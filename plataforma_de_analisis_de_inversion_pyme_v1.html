Despliegue & Conexión (Antigravity + Firebase + Vercel)

Flujo de trabajo para sincronizar tu repo en GitHub, Vercel y Firebase

1. Antigravity Local

Clona y edita el repositorio localmente desde tu terminal/editor:

git clone https://github.com/dnanton-cr/Kawori.git
2. GitHub Repositorio

Cualquier cambio empujado a `main` desencadenará una compilación automática en Vercel:

git push origin main
3. Firebase Firestore

La aplicación guarda dinámicamente las PYMEs en el proyecto kawori-d3a38 bajo la colección `/artifacts/{appId}/public/data/pymes`.

Configuración de Firebase

Para habilitar la persistencia multiusuario en vivo, abre tu proyecto en Firebase Console, genera tu firebaseConfig en Ajustes del proyecto y sustituye las llaves en el script principal de este index.html. Si las llaves están vacías o incompletas, el sistema utilizará automáticamente localStorage como respaldo local.
