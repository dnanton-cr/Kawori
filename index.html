Despliegue & Conexión (Antigravity + Firebase + Vercel)

Flujo de trabajo para sincronizar tu repo en GitHub, Vercel y Firebase

1. Antigravity Local

Clona y edita el repositorio localmente desde tu terminal o IDE:

git clone https://github.com/dnanton-cr/Kawori.git
2. GitHub Repositorio

Cualquier cambio empujado a `main` desencadena la compilación automática en Vercel:

git push origin main
3. Firebase Firestore

La aplicación guarda dinámicamente las PYMEs en el proyecto kawori-d3a38 bajo la colección `/artifacts/{appId}/public/data/pymes`.

Persistencia Multi-Usuario en Vivo

Para habilitar la persistencia multiusuario en vivo con Firebase, abre tu proyecto en Firebase Console, genera tu firebaseConfig en Ajustes del proyecto y sustituye las llaves en el script principal de este archivo.

Si las llaves están vacías o la red está inaccesible, el sistema operará automáticamente con localStorage y soporte completo de respaldo / carga masiva.

Kawori Inversiones Locales

Plataforma de análisis de inversión en PYMEs

Kawori es un entorno ligero y robusto diseñado para que analistas e inversionistas evalúen oportunidades en empresas de la economía real con métricas financieras claras, tesis de inversión y seguimiento cualitativo.

Funciones de Respaldo & Datos
  • Carga Masiva (CSV): Ingesta masiva con autodetección de delimitador.
  • Respaldo de Proyectos (.JSON): Exportación completa de datos y notas.
  • Respaldo de la Aplicación (.HTML): Archivo autónomo con datos incrustados.
  • Sincronización Opcional: Firebase Firestore o LocalStorage automático.
