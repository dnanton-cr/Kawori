Sobre Kawori

Origen de la marca y visión estratégica

Origen y Significado del Nombre

Kawori nace de la fusión de raíces autóctonas de las lenguas chibchas costarricenses (Bribri y Cabécar):

  • Ká Lugar o Suelo: El entorno o espacio propicio donde se siembra y se produce.
  • Wo Semilla o Fruto: El germen con potencial de crecimiento (la PYME local).
  • Ri Agua o Río: El flujo constante de liquidez y capital financiero de la comunidad.

Tres Pilares de Mercado

1. Análisis Riguroso

Métricas claras (EBITDA, FCF, Deuda) adaptadas a la escala real de una PYME.

2. Economía Cercana

Formaliza el financiamiento entre amigos, familiares y la comunidad.

3. Retorno Superior

Rendimiento atractivo respaldado por negocios reales fuera de la banca tradicional.

Guía de Despliegue (Stack Tecnológico)

Hosting en GitHub/Vercel + Persistencia Gratuita en Supabase

1. GitHub Repository

Sube este archivo `index.html` a la raíz de tu repositorio público o privado en GitHub.

2. Vercel Hosting

Conecta Vercel a tu repositorio. El despliegue de archivos estáticos (HTML/JS) es 100% gratuito e instantáneo.

3. Supabase DB

Crea un proyecto gratuito en Supabase para almacenar de forma persistente los perfiles y comentarios.

Esquema SQL Sugerido para Supabase:

-- Tabla Principal: pymes
create table pymes (
  id uuid primary key default gen_random_uuid(),
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  industry text not null,
  location text,
  target_amount numeric,
  min_ticket numeric,
  expected_roi numeric,
  risk_level text,
  term_months integer,
  ebitda numeric,
  free_cash_flow numeric,
  debt_ratio numeric,
  story text,
  investment_thesis text
);

-- Tabla de Comentarios/Feedback
create table comments (
  id uuid primary key default gen_random_uuid(),
  pyme_id uuid references pymes(id) on delete cascade,
  author text,
  content text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
